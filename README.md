기존 번역 3,444개를 1차 검토하고 표현 440개를 수정했습니다. 누락된 UI·장비 슬롯 문구를 보완했으며, 작전 상태·철수·승패 안내 등 실행 문구 33개를 추가로 번역했습니다.

- Light Weight와 .300 BLK 오역, 조준기·양각대·탄창 바닥판·장비 장착 위치 표현 수정.
- 로비 KICK은 추방, 조작의 Kick은 발로 차기로 구분.
- 초기 백업을 유지하면서 이전 버전에서 업데이트할 수 있도록 설치기 수정.
- 설치·재설치·업데이트·복구·변경 파일 차단 테스트 통과. 내장 업데이트 바로가기 등록·버전 선택 테스트 통과.
- 1,330개 수정 파일 재읽기, 변경 데이터 재구성 해시 검증 통과. 새 문구에 쓰인 한글 음절 614개 모두 내장 폰트 지원 확인.
- 원본과 수정 메타데이터의 별도 초기화 테스트 통과.

대상은 Steam OPERATOR 빌드 24091246입니다. 게임을 종료한 뒤 OPERATOR_Korean_v0.1.3_Setup.exe를 실행하세요. 한글 폰트는 게임에 내장되며 Windows 시스템 폰트 설치는 필요하지 않습니다.

v0.1.2의 ‘OPERATOR 한글패치 업데이트’ 바로가기에서도 다운로드할 수 있습니다. 소스만 변경하면 갱신되지 않으며 새 설치파일을 릴리스에 올려야 합니다.
